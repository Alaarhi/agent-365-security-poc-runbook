# Chapter 1 – Agent samples

Minimal examples of Microsoft-native agents that appear in the Agent Registry automatically. Use them to create test agents in [Chapter 1 – Agent Discovery and Inventory](../README.md#12-discover-microsoft-native-agents).

| Folder | Agent type | What it demonstrates |
|---|---|---|
| [`copilot-studio/`](copilot-studio/README.md) | Copilot Studio agent | A reference agent definition, and how a Copilot Studio agent reaches the Registry and the **Requests** tab. |
| [`foundry/`](foundry/README.md) | Microsoft Foundry prompt agent | A Python script based on the Foundry prompt agent quickstart, and the publish step that brings the agent into the Registry. |

Custom agents built with the Agent 365 SDK are covered in [Chapter 2 – Third-Party and Custom Agents](../../chapter-02-third-party-custom-agents/README.md). Their samples are in [`chapter-02-third-party-custom-agents/samples/sdk`](../../chapter-02-third-party-custom-agents/samples/sdk/README.md).
