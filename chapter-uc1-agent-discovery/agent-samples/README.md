# UC1 - Agent samples

Minimal, generic examples of each agent type the Agent Registry can discover. Use these for walkthroughs, demos, or as a starting point if you don't already have a representative agent to onboard.

| Folder | Agent type | What it demonstrates |
|---|---|---|
| [`copilot-studio/`](copilot-studio/) | Microsoft 365 Copilot declarative agent / Copilot Studio Agent Builder | Agent manifest + discovery path for a Microsoft-native agent. |
| [`foundry/`](foundry/) | Azure AI Foundry hosted / prompt agent | Script to create a Foundry hosted agent + discovery path. |
| [`sdk/`](sdk/) | Agent 365 SDK (custom-engine) agents in Node.js, Python, .NET | Hosting-layer skeleton + discovery path via [`microsoft/agent365-skills`](https://github.com/microsoft/agent365-skills). |

Each subfolder has its own README with the discovery path explained.
